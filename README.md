# inverted-index.py

Инвертированный индекс для страниц сайта с дельта-кодированием и кодами Элиаса: гамма и дельта. 

## Установка

```bash
git clone https://github.com/mikhaylovilya/inverted-index.py.git
cd inverted-index.py
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

## Подготовка данных
Исходный файл краулера ожидается из web-crawler.py. 

```bash
python -m inverted_index convert \
  pages.json \
  data/pages.jsonl
```

Команда берёт массив `pages` из JSON и записывает по одной странице на строку JSONL, добавляя последовательный `id`. Остальные поля страницы сохраняются.

## Построение индекса

```bash
python -m inverted_index build data/pages.jsonl data/index.pkl
```

Индекс строится по заголовку и очищенному тексту страницы. Токенизация приводит текст к нижнему регистру, выделяет буквенно-цифровые последовательности и заменяет `ё` на `е`. Для каждого термина хранятся идентификаторы документов: сначала как разности соседних номеров, затем эти разности сжимаются гамма- или дельта-кодом Элиаса. По умолчанию используется гамма-код. Флаг `--coding delta` переключает построение на дельта-код Элиаса.

```bash
python -m inverted_index build data/pages.jsonl data/index.pkl --coding delta
```

Пример вывода:

```json
{
  "documents": 100,
  "terms": 14365,
  "postings": 67183,
  "compressed_bytes": 43186,
  "classic_bytes": 268732,
  "compression_ratio": 0.16070285637735737,
  "saved_percent": 83.92971436226426,
  "coding": "gamma"
}
```

## Поиск

```bash
python -m inverted_index search \
  "Ректор СПбГУ/МГУ" \
  --index data/index.pkl \
  --documents data/pages.jsonl \
  --limit 10
```

По умолчанию используется OR-поиск: документы ранжируются по числу найденных терминов. Для AND-поиска добавьте `--all`. Флаг `--json` выводит результат в JSON вместе со временем поиска.

```bash
python -m inverted_index search \
  "Ректор СПбГУ/МГУ" \
  --index data/index.pkl \
  --documents data/pages.jsonl \
  --json
```

## Бенчмарк

```bash
python -m inverted_index benchmark \
  data/pages.jsonl \
  --query "Ректор СПбГУ/МГУ" \
  --target-docs 40000 \
  --repeats 10 \
  --coding gamma \
  --output data/benchmark-40000.json
```

`--coding` принимает `gamma` или `delta`. Бенчмарк измеряет:

- время сбора несжатых posting-списков;
- время дельта-кодирования разностей и выбранного кода Элиаса;
- общую скорость индексирования;
- размер posting-списков в классическом виде и после сжатия;
- медианное время OR-поиска по сжатому и классическому индексу.

Если в исходном JSONL меньше `--target-docs` документов, корпус циклически повторяется до нужного размера. Это позволяет прогнать сценарий на 40 000 документов, когда реальных страниц меньше. `--target-docs 0` отключает масштабирование.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют:

- токенизацию;
- гамма- и дельта-коды Элиаса вместе с дельта-кодированием разностей, включая точный битовый layout;
- преобразование JSON в JSONL;
- сбор posting-списков;
- дедупликацию документов по термину;
- OR- и AND-поиск;
- сохранение и загрузку индекса;
- бенчмарк и циклическое масштабирование корпуса;
- команды CLI.

## Структура

```text
inverted_index/
  coding.py      разности posting-списков и коды Элиаса (гамма, дельта)
  corpus.py      JSON -> JSONL и чтение документов
  tokenizer.py   токенизация русского и английского текста
  index.py       построение, поиск и сохранение индекса
  benchmark.py   замеры индексирования, сжатия и поиска
  cli.py         команды convert, build, search, benchmark
tests/           pytest-тесты
```
